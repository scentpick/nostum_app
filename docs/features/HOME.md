## 1. 개요

### 1.1 목적
앱의 **중심 게이트웨이**로서 주요 기능에 빠르게 접근하고, 개인화된 콘텐츠를 제공하는 랜딩 페이지

### 1.2 사용자 스토리
- "앱에 들어오면 바로 챗봇과 대화하고 싶어요"
- "오늘 뿌린 향수를 기록하고 확인하고 싶어요"
- "최신 커뮤니티 글을 빠르게 보고 싶어요"
- "인기 향수나 추천 향수를 바로 보고 싶어요"

### 1.3 핵심 역할
- 🎯 **게이트웨이**: 주요 기능 빠른 접근
- 🤖 **챗봇 진입점**: 캐릭터 중심 UI
- 📰 **콘텐츠 큐레이션**: 최신 글, 인기 향수 등
- 👤 **개인화**: 로그인 시 맞춤 콘텐츠

## 2. 기능 상세

### 2.1 메인 캐릭터 섹션 (챗봇 진입점)

#### 현재 구현 상태
- ❌ 캐릭터 UI (미구현)
- ❌ 챗봇 진입 버튼 (미구현)

#### UI 구조
```
┌─────────────────────────────┐
│ Nostum             🔔       │ ← 헤더 (70px)
├─────────────────────────────┤
│                             │
│        🤖                   │ ← 챗봇 캐릭터
│     "안녕하세요!             │   (크게, 중앙)
│   어떤 향수를 찾으세요?"     │
│                             │
│   ┌─────────────────┐       │
│   │ 💬 대화 시작하기 │       │ ← 챗봇 진입 버튼
│   └─────────────────┘       │
│                             │
└─────────────────────────────┘
```

#### 캐릭터 디자인 ✅ 확정
- **스타일**: 친근하고 귀여운 향수병 캐릭터
- **형식**: PNG 또는 SVG (관리자가 제공)
- **표정**: 로그인 상태별 변화
- **말풍선**: 캐릭터 주위에 표시, 클릭 시 내용 변경

#### 말풍선 시스템 ✅ 확정
```
기능:
✅ 캐릭터 클릭 시 말풍선 내용 무작위 변경
✅ 관리자 페이지에서 최대 50개까지 작성 가능
✅ 무작위 순서로 표시

인사말 예시:
비로그인:
- "안녕하세요! 어떤 향수를 찾으세요?"
- "향수에 대해 궁금한 것이 있나요?"
- "오늘은 어떤 향수가 필요하세요?"

로그인:
- "안녕하세요 [닉네임]님!"
- "오늘은 어떤 향수가 필요하세요?"
- "새로운 향수를 찾아보시겠어요?"
```

### 2.2 오늘의 향수 (로그인 시)

#### 기능 개요
로그인한 사용자가 오늘 뿌린 향수를 기록하고 표시

#### UI 구조
```
┌─────────────────────────────┐
│ 🌟 오늘의 향수               │
├─────────────────────────────┤
│ ┌─────┐ ┌─────┐ ┌─────┐    │
│ │🖼️ 1 │ │🖼️ 2 │ │🖼️ 3 │    │ ← 향수 이미지 (작게)
│ │디올  │ │샤넬  │ │조말론│    │   브랜드명
│ └─────┘ └─────┘ └─────┘    │
│                             │
│      [+ 향수 추가하기]       │ ← 추가 버튼
└─────────────────────────────┘
```

#### 기능 상세 ✅ 확정
```
✅ 오늘 뿌린 향수 최대 3개
✅ 향수 검색 후 추가
✅ 클릭 → 향수 상세로 이동
✅ 삭제 가능 (스와이프 or X 버튼)
✅ 자정 지나면 자동 초기화 (PERFUME.md와 일관성)
```

#### 데이터 저장 방식 ✅ 확정
```
기존 perfume_calendar 테이블 활용:
- 오늘 날짜(applied_date = CURRENT_DATE)의 향수만 표시
- 최대 3개까지만 홈 화면에 표시
- 자정 자동 초기화 (PERFUME.md의 자동 변경 로직과 연동)

장점:
✅ 기존 캘린더 시스템과 통합
✅ 이력 유지 (캘린더에서 과거 기록 확인 가능)
✅ 중복 개발 방지
```

## 3. 데이터베이스 ✅ 확정

### 3.1 필요한 테이블

#### `perfume_calendar` (오늘의 향수) ✅ 확정
홈 화면의 "오늘 뿌린 향수"는 **`perfume_calendar` 테이블**을 활용합니다.

**설계 결정:**
- ✅ 기존 `perfume_calendar` 테이블 재사용 (PERFUME.md 참고)
- ✅ `applied_date = CURRENT_DATE`인 향수만 표시
- ✅ 최대 3개까지 홈 화면에 표시
- ✅ 자정 자동 초기화 (PERFUME.md의 자동 변경 로직과 연동)
- ✅ 이력 유지 (캘린더에서 과거 기록 확인 가능)

**장점:**
- 중복 테이블 생성 방지
- 캘린더 기능과 통합
- 데이터 일관성 유지

### 3.2 관련 테이블 (이미 존재)
- `perfume_calendar` (오늘의 향수) ✅ PERFUME.md 참고
- `community_posts` (최신 글)
- `perfumes` (인기 향수)
- `user_favorites` (찜한 향수)
- `notifications` (알림)

## 4. API

### 4.1 필요한 API

#### 오늘의 향수 ✅ 확정 (perfume_calendar 활용)
```typescript
// 오늘의 향수 조회 (perfume_calendar 테이블에서)
getTodayPerfumes(userId: string): Promise<ApiResponse<TodayPerfume[]>>
// → applied_date = CURRENT_DATE, 최대 3개

// 오늘의 향수 추가 (perfume_calendar 테이블에)
addTodayPerfume(userId: string, perfumeId: string, notes?: string): Promise<ApiResponse<PerfumeCalendarEntry>>

// 오늘의 향수 삭제 (perfume_calendar 테이블에서)
removeTodayPerfume(userId: string, perfumeId: string): Promise<ApiResponse<void>>
```

#### 최신 게시글
```typescript
// 홈 화면용 최신 글 (모든 카테고리)
getRecentPosts(limit: number = 5): Promise<ApiResponse<CommunityPost[]>>
// → created_at DESC, is_deleted = false
```

#### 인기 향수
```typescript
// 이번 주 인기 향수
getPopularPerfumes(limit: number = 3): Promise<ApiResponse<Perfume[]>>
// → 최근 7일 찜한 수 기준
```

#### AI 추천 (선택)
```typescript
// 개인화 추천 (로그인 시)
getRecommendedPerfumes(userId: string, limit: number = 3): Promise<ApiResponse<Perfume[]>>
// → 찜한 향수, 리뷰 기반 추천
```

1. 앱 열기 → 캐릭터 + 최신 글 표시
2. [대화 시작] 클릭 → 챗봇 탭
3. 게시글 클릭 → 커뮤니티 > 상세
4. [더보기] 클릭 → 커뮤니티 탭

### 8.2 로그인 사용자
1. 앱 열기 → 캐릭터 + 오늘의 향수 + 최신 글
2. 오늘의 향수 없음 → [+ 추가] 클릭
3. 향수 검색 → 선택 → 추가 완료
4. 오늘의 향수 클릭 → 향수 상세
5. 🔔 알림 클릭 → 알림 목록
