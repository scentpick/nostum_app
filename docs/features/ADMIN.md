## 1. 개요

### 1.1 목적
앱과 별도로 관리자가 효율적으로 콘텐츠를 관리하고, 사용자를 관리하며, 통계를 확인할 수 있는 웹 기반 관리 도구

### 1.2 주요 목표
- 🎯 **개발 효율**: Supabase 직접 접근 대신 편리한 UI
- 🎯 **운영 효율**: 게시글, 댓글, 신고 빠르게 처리
- 🎯 **데이터 관리**: 향수 DB, 사용자 관리
- 🎯 **통계 분석**: 앱 사용 현황 파악

### 1.3 접근 방식
- **URL**: 숨겨진 경로 (`/nadmin` 또는 별도 도메인)
- **인증**: 관리자 권한 필수 (`role = 'admin'`)
- **플랫폼**: 웹 전용 (PC에서 관리)

## 4. 데이터베이스

### 4.1 필요한 뷰 (View)

#### 관리자용 통합 뷰
```sql
CREATE VIEW admin_posts_view AS
SELECT 
  p.*,
  u.nickname as author_name,
  u.role as author_role,
  c.name as category_name,
  COUNT(DISTINCT pc.id) as actual_comment_count,
  COUNT(DISTINCT r.id) as report_count
FROM community_posts p
LEFT JOIN profiles u ON p.user_id = u.id
LEFT JOIN board_categories c ON p.category_id = c.id
LEFT JOIN post_comments pc ON p.id = pc.post_id
LEFT JOIN reports r ON r.target_id = p.id AND r.target_type = 'post'
GROUP BY p.id, u.nickname, u.role, c.name;
```
